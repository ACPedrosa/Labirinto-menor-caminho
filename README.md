# Labirinto-menor-caminho
Este repositório foi criado com a finalidade de armazenar a implementação de um algorimtmo para encontrar o menor caminho dentro de um labirinto utilizando grafos

---



## Como Executar o Programa

Siga os passos abaixo para compilar e rodar o projeto em seu ambiente:

### 1. Preparação
Abra o terminal e navegue até a pasta raiz do programa:
```bash
cd caminho/para/o/projeto/LABIRINTO-MENOR-CAMINHO

```

### 2. Compilação

Utilize o comando `make` para compilar os módulos (C e C++) automaticamente. Isso criará o arquivo executável chamado **labirinto**:

```bash
make

```

### 3. Inicialização

Com o executável gerado, rode o seguinte comando para iniciar a aplicação.

```bash
./labirinto

```

### 4. Interação

Agora, basta seguir as instruções apresentadas no **Menu Interativo** do terminal para carregar os arquivos e realizar os testes.
